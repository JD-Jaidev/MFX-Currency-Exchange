# MFX ~ Multi-Currency Exchange & Market Trends

A modern, responsive, futuristic fintech dashboard web application engineered for real-time currency conversion, historical exchange-rate trends, and market volatility insights.

---

## 🚀 Live Demo 
[MFX Currency converter](https://mfx-currency-exchange.vercel.app/)

---

## 🛠️ Project Structure

```text
MFX/
├── index.html          # Semantic HTML5 application structure
├── css/
│   ├── style.css       # Design tokens, glassmorphism, gradients, animations
│   └── responsive.css  # Breakpoints for mobile, tablet, and desktop
├── js/
│   ├── api.js          # Frankfurter API client (currencies, latest, historical)
│   ├── storage.js      # LocalStorage manager (favorites, recents, theme)
│   ├── chart.js        # Chart.js initialization, gradients, stats calculations
│   ├── converter.js    # Conversion logic, searchable dropdowns, swap, copy
│   ├── ui.js           # Theme toggle, toasts, navigation, quick pairs
│   └── app.js          # App bootstrap and event orchestrator
└── README.md           # Documentation
```
